Words Into Motion Setup

  1. Install Words Into Motion from the Google Workspace Marketplace.
  2. Open a Google Slides™ presentation.
  3. Choose Extensions > Words Into Motion > Open Words Into Motion.
  4. Open Settings in the sidebar.
  5. Paste your Groq API key and select Save API Key.
  6. Enter a single-step addition or subtraction word problem.
  7. Select Generate Storyboard.
  8. Review the preview, then select Insert Slides.

Get a Groq API Key

Visit Groq API Keys, sign in, create a key, and copy it into Words Into Motion. Keep your API key private.
