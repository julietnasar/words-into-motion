Words Into Motion Admin Configuration

Words Into Motion does not require domain-wide administrator configuration for basic use.

Administrator Checklist

Administrators should confirm that users are allowed to:

  • Install approved Google Slides™ add-ons.
  • Use Apps Script add-ons.
  • Connect to external services required by the add-on.
  • Access https://api.groq.com if the organization uses network filtering.

Teachers need an individual Groq API key unless their organization provides another approved process. Administrators can control Marketplace app access through the Google Admin console.
