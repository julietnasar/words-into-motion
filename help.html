Words Into Motion Help

Words Into Motion works best with simple elementary addition and subtraction word problems.

Example

Maria has 5 apples. She gives away 2. How many apples does Maria have left?

Tips

  • Use one clear main character.
  • Use one countable object.
  • Use one operation.
  • Review every generated slide before using it with students.
  • If the storyboard looks wrong, simplify the wording and generate again.
